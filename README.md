# atime Gallery

[animint2](https://cran.r-project.org/web/packages/animint2/) is an R package for animated and interactive data visualizations. 

[atime](https://cran.r-project.org/web/packages/atime/) is an R package for asymptotic benchmarking.

This repository hosts the [atime gallery](https://tdhock.github.io/gallery-atime/), which contains visualizations created with animint2, using results from atime.
